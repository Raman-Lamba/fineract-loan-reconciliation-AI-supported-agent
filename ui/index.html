Do not run .\start.ps1 -Seed or seed.load_fineract against a real Fineract. The seed is for the demo sandbox only: it enables currencies and creates payment types, a loan product, 200 clients and 260 back-dated loans.

3. What the agent expects from your Fineract

In FineractHow the agent uses it
Each loan's External IdYour own loan reference. It becomes loan_ref everywhere: the matcher, the queue, the ledger and the partner report. A loan with no External Id is known by its Fineract account number instead (for example 000000042). Excel drops leading zeros from such a number, so decide those lines on this page, not in Excel.
The client's display name on the loanMatched against the payer's name in the bank narration. The first word is taken as the first name and the rest as the surname.
The loan's repayment scheduleEach instalment's due date and total due. A line is posted automatically only if its amount equals an instalment exactly and its date is within 5 days of the due date.
The loan's account numberA narration containing SCPL + the 9-digit account number names the loan directly. This prefix is the synthetic lender's; a different one needs a one-line change in matcher/match.py.
Payment types named UPI, NEFT, IMPS, NACHThe channel found in the narration is posted as the payment type. A missing type does not stop the posting; the repayment just has none.
INR as an enabled currencyAmounts are rupees with two decimals. Loans in another currency are not supported.
Repayment External IdThe agent posts each repayment with the bank's UTR as the transaction's External Id (and as the receipt number). Fineract keeps that unique, so the same bank line can never be posted twice, even from a second machine.

What the agent never does. It never creates or changes clients, loans, products, currencies or payment types (only the demo seed does, and that is for the sandbox). It never reverses or edits a repayment. It never posts a line that fits two loans, an amount that is not an instalment, or anything a person rejected. The only call that writes is POST /loans/{id}/transactions?command=repayment.

4. Where to see the results in Mifos

  • Open a loan:
    The two numbers are Fineract's client id and loan id (both are in data\schedules.json). The candidate cards on the Review tab link to the loan's /general page the same way. Pattern read from the route table of Mifos web app 1.14, the version in the sandbox.
  • On the loan's Transactions tab, each repayment the agent posted has the bank's UTR in the External Id column. Open the transaction to see its payment details: payment type and receipt number (the UTR again).
  • The loan's Repayment Schedule tab shows the instalment as paid, and the loan leaves arrears once nothing is overdue.
  • From the API: GET /loans/{loanId}/transactions/external-id/{UTR} returns the repayment.

5. If something goes wrong

What you seeWhat to do
Connection failed, or check 1 failsFineract is not running or the API address is wrong. It must end in /fineract-provider/api/v1. Fix it on the Connect tab and press Save; no restart is needed.
Error 400 on every callUnknown tenant: fix it on the Connect tab.
Error 401Wrong user or password: fix them on the Connect tab.
"REFUSED" or "row N: ..." on the Statement tabThat row of your file cannot be read with the columns chosen (an amount or date in another form, or a credit with no reference). Check the column choices; if they are right, fix or remove that row in the file (a cash deposit with no reference is recorded by hand in Fineract) and choose the file again.
"AI reader did not run" or "not used"No key saved, no consent ticked, or Anthropic's API did not answer. Nothing is lost: choose the columns by hand, and unread narrations go to a person.
Error 403The user lacks a permission (table in step 1) or cannot see the loans' office.
Everything is slow (2 seconds a call)Use 127.0.0.1 instead of localhost in MIFOSX_BASE_URL.
A row says loan_ref '…' is not a known loanThe loan is newer than data\schedules.json, or the reference is mistyped. Run statement.fetch_schedules again.
queue.csv is open in another programClose it in Excel, then press the button again.
this txn_id is already in Fineract, but not on this loanThat UTR was posted to another loan earlier. Find it in Mifos before deciding; the agent will not post it a second time.
The queue is emptyNothing is waiting. New unclear lines arrive with the next .\start.ps1 -Reconcile or review.build.
"this page is out of date: reload it"The server was restarted. Reload the page.
